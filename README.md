# Nexan Ai v14: দ্রুত গেস্ট মোড, অ্যাকাউন্ট বাধ্যতামূলক, প্রোফাইল ও বাগ ফিক্স

## v14-এ কী বদলেছে
- **গেস্ট মোড দ্রুত:** সাইট খুললেই ইন্টারফেস দেখা যায়, সার্ভারের উত্তরের জন্য অপেক্ষা করতে হয় না। অ্যাকাউন্ট যাচাই ও জ্ঞানভান্ডার (kb) ব্যাকগ্রাউন্ডে লোড হয়। গেস্ট মোডে চ্যাট হিস্ট্রি/লোকাল ডেটা পড়াই হয় না।
- **টেক্সট ফিচার চালাতে অ্যাকাউন্ট লাগে:** মেসেজ পাঠানো, মাইক/ভয়েস, Create image/Search/PDF/Code কার্ড, ফাইল অ্যাটাচ/পেস্ট। গেস্ট এগুলোয় চাপলে Login/Register খোলে (লেখা মেসেজ থেকে যায়)। সার্ভারেও `/api/chat` ও `/api/image` লগইন ছাড়া 401 দেয় (KV বাইন্ডিং থাকলে)।
- **প্রোফাইল:** মোবাইলের টপ বারে নতুন প্রোফাইল বাটন (গেস্টের জন্য সাইন ইন, লগইনের পর ছবি → My Profile)। ডেস্কটপে সাইডবারের প্রোফাইল আগের মতো।
- **বাগ ফিক্স:**
  1. সাইন আউট বা অ্যাকাউন্ট ডিলিটের পরেও আগের ইউজারের কথোপকথন স্ক্রিনে থেকে যেত। এখন পরিষ্কার গেস্ট ভিউ আসে।
  2. গেস্ট আগের সেভ করা লোকাল চ্যাট দেখতে পারত। এখন লগইনের পরেই হিস্ট্রি লোড হয়।
  3. অ্যাকাউন্ট যাচাই শেষ হওয়ার আগে Send চাপলে গেট এড়িয়ে যাওয়া যেত।
  4. ইন্টারনেট সমস্যায় শুরুতেই জোর করে লগইন স্ক্রিন খুলে যেত। এখন গেস্ট ভিউতেই থাকে ও সংযোগের বার্তা দেখায়।
  5. মোবাইলে ড্যাশবোর্ডের ট্যাবগুলো চাপা খেয়ে লেখা কেটে যেত, আর ✕ বাটন সরে যেত। এখন স্ক্রল হয় ও ✕ সবসময় দেখা যায়।

## আপডেট করবেন যেভাবে
`worker.js` আর `index.html` GitHub-এ replace করে commit করুন। `wrangler.toml`, KV বাইন্ডিং ও সব ভ্যারিয়েবল (API_KEY, ADMIN_PASSWORD, GOOGLE_*) আগের মতোই। নতুন কোনো সেটিং লাগে না।

## জেনে রাখুন
- KV বাইন্ডিং না থাকলে অ্যাকাউন্ট সিস্টেমই নেই, তাই সাইট আগের মতো খোলা থাকে।
- চ্যাট হিস্ট্রি এখনো ব্রাউজারে সেভ হয়, অ্যাকাউন্ট-ভিত্তিক নয়। একই ব্রাউজারে অন্য অ্যাকাউন্টে লগইন করলে সেই ব্রাউজারের পুরনো চ্যাট দেখা যাবে। গেস্ট দেখতে পায় না, কিন্তু অ্যাকাউন্ট ভাগ করা ডিভাইসে এটা মাথায় রাখুন।

## লগইন স্ক্রিন (v11)

- **এখনো ব্যাকএন্ড কানেক্ট নয়:** "Forgot password" (ইমেইল সার্ভিস লাগবে) আর "Continue with Google" (Google OAuth ক্লায়েন্ট লাগবে)। সার্ভার এখন সৎভাবে 501 বার্তা দেয়। কোথায় কানেক্ট করবেন তা `worker.js`-এ `Placeholders` কমেন্টে লেখা আছে।
- লোকালি চালাতে: ফোল্ডারে `npx wrangler dev`। সরাসরি deploy করতে নিচের সেটআপ।

## ডিজাইন (v10)
- Claymorphism: নরম কার্ড, বাটন, মেসেজ বাবল (হালকা ভেতর/বাইরের ছায়া)।
- Glassmorphism শুধু: সাইডবার, টপ বার, মেসেজ বক্স, ডায়ালগ, লগইন কার্ড, ড্যাশবোর্ড নেভ, টোস্ট। ব্লার মাত্র ১০px, আর ব্লার সাপোর্ট না থাকলে বা ধীর ডিভাইসে সলিড রঙ।
- নতুন সেটিংস পেজ বা থিম কন্ট্রোল নেই। চ্যাট, API, ভয়েস, লোগো অ্যানিমেশন অপরিবর্তিত।
- ড্যাশবোর্ড Home-এ সাম্প্রতিক কথোপকথন (চাপলে সেই চ্যাট খোলে)।
- Android কিবোর্ড, সেফ-এরিয়া, ৪৪px টাচ টার্গেট, reduced-motion সাপোর্ট।

## সেটআপ (ফোন থেকেই)
1. Cloudflare → Storage & databases → KV → Create namespace (নাম nexan-users)। ID কপি করুন।
2. GitHub-এ `wrangler.toml` খুলে শেষের ৩টা লাইনের `#` মুছে `PASTE_YOUR_KV_NAMESPACE_ID`-এর জায়গায় ID বসান।
3. GitHub-এ `worker.js` আর `index.html` replace করে commit করুন (Add file → Upload files)।
4. Cloudflare নিজে deploy করবে। সাইট খুলে Sign up করুন।
- নতুন কোনো Secret লাগে না। আগের `API_KEY`, `ADMIN_PASSWORD`, `ACCESS_CODE` যেমন আছে তেমনই থাকবে।
- KV বাইন্ডিং না থাকলে সাইট আগের মতো লগইন ছাড়া চলবে, অ্যাকাউন্ট বন্ধ থাকবে।

## জেনে রাখুন
- KV চালু থাকলে লগইন ছাড়া চ্যাট/ছবি চলে না (আপনার কোটা বাঁচে)।
- পাসওয়ার্ড PBKDF2-SHA256 দিয়ে হ্যাশ হয়ে KV-তে থাকে, সেশন HttpOnly কুকিতে (৩০ দিন)।
- চ্যাট হিস্ট্রি এখনও ডিভাইসেই সেভ থাকে, অ্যাকাউন্টে সিঙ্ক হয় না।
- ইমেইল ভেরিফিকেশন ও "পাসওয়ার্ড ভুলে গেছি" নেই (ইমেইল সার্ভিস লাগে)।
- ফ্রি প্ল্যানে CPU সীমা ১০ms। লগইনে পাসওয়ার্ড হ্যাশ ভারী কাজ, তাই "Exceeded CPU" এরর এলে Workers Paid ($5/মাস) নিন।

## v13: গেস্ট ব্রাউজিং + Google সাইন-ইন
- সাইট খুললে লগইন স্ক্রিন আসে না। গেস্ট ইন্টারফেস দেখতে পারে। মেসেজ লিখে Send বা Enter (বা মাইক/ভয়েস) চাপলে আগের অ্যানিমেটেড Login/Register খোলে। লেখা মেসেজ থেকে যায়, লগইনের পর ইনপুটে ফিরে আসে, **নিজে থেকে পাঠানো হয় না**; দেখে Send চাপতে হয়। ✕ বা Esc দিলে গেস্টই থাকে, কিছু পাঠানো হয় না।
- সাইডবারের নিচে গেস্টের জন্য "Sign in" বাটন। Sign out করলে এখন গেস্ট ভিউতে ফেরে।
- Login ও Register দুটোতেই "Continue with Google" (আসল OAuth 2.0 code flow + PKCE, সবটা worker.js-এ; secret ব্রাউজারে যায় না)।
- নতুন Google ইউজার আলাদা Signup ছাড়াই অ্যাকাউন্ট পায় (নাম, ভেরিফাইড ইমেইল, ছবি)। ইউজার Google-এর স্থায়ী `sub` আইডি দিয়ে চিহ্নিত।
- একই ইমেইলে পাসওয়ার্ড অ্যাকাউন্ট থাকলে চুপচাপ মার্জ হয় না। পাসওয়ার্ডে লগইন করে Account settings → "Connect Google" চাপতে হয়।
- Google-only অ্যাকাউন্ট: পাসওয়ার্ড ঐচ্ছিক (Settings থেকে সেট করা যায়), ডিলিটে পাসওয়ার্ডের বদলে ইমেইল লিখে নিশ্চিত করতে হয়।

### Google সেটআপ (একবার, আপনাকে করতে হবে)
1. console.cloud.google.com → APIs & Services → OAuth consent screen: App name, support email দিন, scopes: `openid email profile`। (Testing মোডে শুধু Test users লগইন করতে পারে; সবার জন্য Publish করুন।)
2. Credentials → Create credentials → OAuth client ID → Web application।
   - Authorized redirect URI: `https://<আপনার-সাইট>/api/auth/google/callback` (কাস্টম ডোমেইন থাকলে সেটাও আলাদা করে দিন)।
3. Cloudflare → আপনার প্রজেক্ট → Settings → Variables and Secrets: `GOOGLE_CLIENT_ID` (Text) ও `GOOGLE_CLIENT_SECRET` (**Secret**)।
4. KV বাইন্ডিং (`KV`) থাকতে হবে (উপরের সেটআপ)। এরপর নতুন করে deploy করুন।
- এই দুটো ভ্যারিয়েবল না থাকলে বাটন চাপলে "Google সাইন-ইন চালু হয়নি" দেখায়, আর কিছু ভাঙে না।
- ঐচ্ছিক: `GOOGLE_REDIRECT_URI` দিয়ে redirect URI জোর করে ঠিক করা যায়।

### জেনে রাখুন
- সার্ভার-সাইড গেট: `/api/chat` ও `/api/image` KV চালু থাকলে লগইন ছাড়া 401 দেয়। KV না থাকলে অ্যাকাউন্ট সিস্টেমই নেই, তাই সাইট আগের মতো খোলা থাকে।
- চ্যাট হিস্ট্রি এখনো ব্রাউজারে (IndexedDB) সেভ হয়, অ্যাকাউন্ট-ভিত্তিক নয়। একই ব্রাউজারে সাইন আউটের পর/অন্য ইউজার লগইন করলে পুরনো চ্যাট দেখা যেতে পারে। শেয়ার্ড ডিভাইসে ব্যবহারের আগে এটা মাথায় রাখুন।
- Google রিডাইরেক্টের সময় শুধু টেক্সট মেসেজ ধরে রাখা হয়; সংযুক্ত ফাইল/ছবি রিডাইরেক্টে হারাতে পারে।
